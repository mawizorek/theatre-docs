# Ogunquit Playhouse

Venue records. Currently electrics only; other departments arrive as their
paperwork gets written up.

!!! note "Why a venue lives on a general-practice site"

    This site holds both, and the boundary runs between PAGES rather than
    between repos: a practice page describes how a thing is generally done, a
    venue page records what is true of one building. Sitting them side by side
    is the point, because a venue page should be able to link to the practice
    instead of restating it.
